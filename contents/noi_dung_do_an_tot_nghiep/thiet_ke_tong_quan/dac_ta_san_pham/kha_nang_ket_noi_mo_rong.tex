\subsection{Khả năng kết nối và Mở rộng mô-đun}
    \begin{itemize}
        \item \textbf{Khe cắm mở rộng:} Gồm 03 khe cắm chuẩn hóa (01 WAN Module, 02 LAN Module) hỗ trợ thay thế linh hoạt.
        \item \textbf{Giao diện tại khe cắm:} Hỗ trợ đầy đủ các giao tiếp UART, SPI, I2C, USB 2.0 và các chân GPIO chức năng.
        \item \textbf{Các mô-đun Adapter hỗ trợ:}
        \begin{itemize}
            \item WAN: LTE 4G, Ethernet\dots
            \item LAN: Zigbee, LoRaWAN, RS-485\dots
        \end{itemize}
        \item \textbf{Lưu trữ cục bộ:} Khe cắm thẻ nhớ Micro SD hỗ trợ giao tiếp SDIO 4-bit phục vụ việc ghi nhật ký dữ liệu ngoại tuyến.
    \end{itemize}
